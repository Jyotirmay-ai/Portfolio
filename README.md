# Portfolio

HUD Portfolio & Interactive Resume of **Jyotirmay Biswas** (Aspiring AI Engineer & Data Scientist).

---

## 🚀 Features & Architecture
- **Interactive Holographic Avatar:** Cyberpunk HUD avatar frame displaying `profile Picture.png` with scanline effects.
- **20 Verified Credentials Archive:** Dedicated interactive certifications center in `certificates.html` with category filters (AI & Data Science, Hackathons, Industry Simulations, Space & Conferences, Academic Records).
- **Interactive 3D Three.js Engine:** Real-time particle field, Torus Knot wireframe cyber core, and mouse parallax tracking.
- **Interactive Resume & Direct PDF Download:** Modular tabbed resume (Objective, Education, Key Projects, Skills) with direct PDF download.
- **Live Project Simulations:** Interactive RAR (Retrieval-Augmented Ranking) pipeline and Ghost Protocol Tor chat simulators.
- **Interactive Bash CLI Terminal:** Command-line terminal supporting `help`, `bio`, `skills`, `projects`, `certs`, `goal`, `matrix`, `history`, and tab-completion.
